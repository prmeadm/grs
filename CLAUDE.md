# Vkadre — Telegram Mini App для приёма заказов

Mini App сети фотостудий «В кадре». Агенты в Telegram-группе открывают приложение по закреплённой кнопке,
выбирают услуги (печать фото, рамки, таблички, ретушь), прикрепляют фото, для табличек вводят ФИО усопшего
и даты. Заказ пишется одной строкой в Google-таблицу и дублируется сообщением в группу вместе с фото.

Владелец проекта не программист: объясняй по-русски, коротко и по шагам. Всё, что можно сделать командами,
делай сам; руками владельца — только логины и то, что нельзя автоматизировать (BotFather, настройки Google).

## Устройство

| Часть | Где живёт | Как обновляется |
|---|---|---|
| `index.html` — фронтенд Mini App | этот репозиторий (`prmeadm/grs`), GitHub Pages: https://prmeadm.github.io/grs/ | `git push` в `main`, Pages собирается 1–2 мин |
| `apps-script/Code.gs` — бэкенд | Google Apps Script, привязан к таблице «Заявки Мележа» | `clasp push` + `clasp deploy` (см. ниже) |
| Прайс | лист «Прайс» в таблице | владелец правит сам, код не нужен |

- Фронтенд ходит в бэкенд по `API_URL` (в начале `<script>` в `index.html`): GET — прайс, POST — загрузка фото (`action: 'upload'`) и заказ.
- Бэкенд проверяет подпись Telegram `initData`, пишет лист «Заказы» (по колонке на услугу, ФИО/даты табличек, в конце «Сумма заказа»), кладёт фото на Google Диск, шлёт заказ в группу через Bot API.
- `onEdit` в таблице: пересчёт суммы при ручной правке количества; сброс кэша прайса при правке листа «Прайс».
- Секреты (`BOT_TOKEN`, `CHAT_ID`, `APP_LINK`) — **только** в свойствах скрипта Apps Script. Репозиторий публичный: никогда не коммить токены, ID и ссылки с ключами.

## Как выкатывать изменения

### Бэкенд (Code.gs)
1. Подними `APP_VERSION` в `Code.gs` на 1.
2. `cd apps-script && npx @google/clasp push -f`
3. `npx @google/clasp deploy -i AKfycbyWZOok4ZFCOkRm89GDrKQIdt0QSzuVjiQuN7b2mbrkjHtGmzEyWX5ljvyFK7l6D_Hm -d "что изменилось"` — обновляет **существующее** развёртывание, URL не меняется. Никогда не создавай новое развёртывание без `-i`: у него будет другой URL.
4. Проверь: `curl -sL "API_URL?check=$RANDOM"` → в JSON `"version"` = новому `APP_VERSION`.
5. Если поменялась структура листов — попроси владельца запустить `setup` в редакторе Apps Script (или `clasp run setup`, если настроено).

### Фронтенд (index.html)
1. Не трогай строку `API_URL`, если не меняется развёртывание.
2. `git add -A && git commit -m "..." && git push`
3. Telegram кэширует страницу: попроси владельца в @BotFather → `/myapps` → приложение → Edit Web App URL поставить `https://prmeadm.github.io/grs/?v=N` со следующим номером. Спроси у владельца, какой номер стоит сейчас, и запиши сюда последний: `?v=?`.

### Проверка перед пушем
- `node --check apps-script/Code.gs` (скопировав в .js) и проверка синтаксиса скрипта из `index.html`.
- Для интерфейса удобно открыть `index.html` в Playwright с подменой `API_URL` (мок GET/POST), без Telegram — там видна запасная кнопка вместо нативной.

## Первая настройка (один раз)

1. Репозиторий: если папка пустая — `git clone https://github.com/prmeadm/grs.git .`, затем положи сюда файлы из этого пакета. Если в репозитории уже есть `index.html` — перенеси из него текущее значение `API_URL` в новый `index.html`.
2. Владелец логинится в GitHub (`gh auth login` или git credential manager) — сам, в браузере.
3. Владелец включает Apps Script API: https://script.google.com/home/usersettings → «Google Apps Script API» → Вкл.
4. `npx @google/clasp login` — владелец входит в Google в браузере (тот же аккаунт, где таблица).
5. Впиши Script ID в `apps-script/.clasp.json` и в этот файл, Deployment ID — в этот файл.
6. Владелец в Apps Script → ⚙️ Настройки проекта → Свойства скрипта добавляет `BOT_TOKEN`, `CHAT_ID`, `APP_LINK`.
7. Первый `clasp push -f` заменит файлы проекта (старый `Код.gs` удалится — это нормально, его содержимое теперь в `Code.gs`). Затем `clasp deploy -i ...` и проверка версии.

## Правила, которые владелец уже утвердил

- Один заказ = одна строка; колонка на каждую услугу (в ячейке количество), «Сумма заказа» последней колонкой.
- Сообщение в группу: каждое поле с новой строки.
- Фото — к печати фото (все размеры, с рамкой и без) и к сублимационной табличке; столько фото, сколько штук. Фото уходят в группу файлами без сжатия, с подписью услуги.
- ФИО усопшего / дата рождения / дата смерти — для всех табличек (сублимация и гравировка), обязательны, отдельные столбцы в таблице.
- Цены всегда считаются на сервере по листу «Прайс».
- Без платных и сторонних сервисов: только Telegram Bot API, Google (Apps Script, Sheets, Drive) и GitHub Pages.
